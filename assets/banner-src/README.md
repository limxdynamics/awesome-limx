# Banner source

`banner.html` draws all four banners at 2560 × 800. Open it with `#en`, `#cn`, `#ja` or `#ko`
after the file name and take a screenshot, or run:

```bash
npm i playwright && node render.js
```

Section labels, the tagline and the robot chips live in the `T` object and the chip list in
`banner.html`. Keep the labels identical to the section headings in each README.
